# دستیار هوشمند ویزیتور فیس دوکس (PWA)

اپلیکیشن وب پیش‌رونده (PWA) فارسی برای ویزیتورهای شرکت فیس دوکس. این اپ به صورت آفلاین و آنلاین کار می‌کند و در لحظه پرزنت، پاسخ‌های علمی و مقایسه‌ای برای پزشکان و داروخانه‌ها ارائه می‌دهد.

## ✨ ویژگی‌ها

- **کاملاً آفلاین**: بدون نیاز به اینترنت، تمام پاسخ‌ها از دیتابیس محلی
- **نصب روی گوشی**: PWA قابل نصب روی Android و iOS
- **رابط فارسی RTL**: طراحی شده برای کاربران ایرانی
- **موتور هوش مصنوعی محلی**: تشخیص intent و پاسخ‌دهی هوشمند بدون API خارجی
- **۳ جمله طلایی**: آماده برای پرزنت به پزشک
- **ضبط صوتی (STT)**: تبدیل گفتار به متن با Web Speech API
- **بازخورد یادگیری**: ثبت 👍/👎 برای بهبود پاسخ‌ها
- **گزارش‌گیری**: ذخیره خودکار گزارش‌های ویزیت
- **خروجی JSON**: خروجی گرفتن از گزارش‌ها برای تیم مارکتینگ

## 🚀 راه‌اندازی

### روش ۱: اجرای محلی (ساده)

```bash
cd facedoux-pwa
python3 -m http.server 8000
# یا
npx serve -p 8000
```

سپس مرورگر را باز کنید: `http://localhost:8000`

### روش ۲: نصب به عنوان اپ

1. اپ را در Chrome/Safari باز کنید
2. روی منوی مرورگر → "Add to Home Screen" / "نصب برنامه"
3. اپلیکیشن به صورت آیکون روی گوشی نصب می‌شود

### روش ۳: دیپلوی روی سرور

فایل‌ها را در هر هاست استاتیک آپلود کنید:
- **GitHub Pages** (رایگان)
- **Netlify** (رایگان)
- **Vercel** (رایگان)
- **Cloudflare Pages** (رایگان)

> ⚠️ **نکته مهم**: PWA باید از طریق HTTPS یا localhost سرو شود.

## 🧪 تست عملکرد

### تست ۱: رابط کاربری
1. اپ را باز کنید
2. روی یک محصول از تب "محصولات" کلیک کنید
3. باید مودال با اطلاعات کامل، ترکیبات، مقایسه و ۳ جمله طلایی نمایش داده شود

### تست ۲: چت هوشمند
سوالات زیر را در تب "گفتگو" امتحان کنید:
- «ترکیبات این محصول چیست؟»
- «مقایسه با Lá Farrerr»
- «۳ جمله طلایی را بگو»
- «چه عوارضی دارد؟»

### تست ۳: حالت آفلاین
1. اپ را در مرورگر باز کنید
2. اینترنت را قطع کنید (DevTools → Network → Offline)
3. اپ باید همچنان کار کند

### تست ۴: Service Worker
در Chrome DevTools:
- **Application** → **Service Workers** → باید ثبت شده باشد
- **Application** → **Manifest** → باید valid باشد
- **Lighthouse** → اجرا و گرفتن امتیاز PWA

### تست ۵: ضبط صوتی
روی دکمه 🎤 بزنید (در Chrome/Edge باید کار کند)

## 📊 داده‌های نمونه

## 🔧 سفارشی‌سازی

### اضافه کردن محصول جدید
فایل `js/products.js` را ویرایش کنید و یک آیتم جدید به آرایه `PRODUCTS` اضافه کنید:

```javascript
{
  id: 'product-id',
  name: 'نام محصول',
  category: 'دسته',
  description: 'توضیح کوتاه',
  icon: '💊',
  composition: ['ماده ۱', 'ماده ۲'],
  indications: ['کاربرد ۱', 'کاربرد ۲'],
  scientificSources: [
    { code: 'PubMed: 12345', text: 'توضیح منبع' }
  ],
  competitors: [
    { name: 'نام رقیب', weakness: 'نقطه ضعف' }
  ],
  goldenSentences: [
    'جمله ۱: برتری فیس دوکس',
    'جمله ۲: نقطه ضعف رقیب',
    'جمله ۳: سود نهایی'
  ],
  faqs: [
    { q: 'سوال؟', a: 'پاسخ.' }
  ]
}
```

```css
  /* ... */
}
```

## 🏗 معماری

### موتور AI محلی (`ai-engine.js`)

موتور هوش مصنوعی به صورت کاملاً سمت-کلاینت کار می‌کند و از تکنیک‌های زیر استفاده می‌کند:

1. **تشخیص Intent**: با regex و tokenization ساده
2. **جستجوی محصول**: بر اساس امتیازدهی به توکن‌ها
3. **پاسخ‌دهی مبتنی بر template**: با context-aware
4. **سیستم بازخورد**: ذخیره در `localStorage`

### Service Worker (`sw.js`)

- **Cache-First** برای فایل‌های استاتیک
- **Network-First** با fallback به cache
- نسخه‌بندی: `facedoux-v1.0.0`
